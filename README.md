# Picture Book Writer

A friendly desktop word processor made just for writing **children's picture books**. Built for people who aren't "computer people": big buttons, plain words, and it saves your work by itself.

▶️ **Walkthrough video:** [`demo/Picture-Book-Writer-Demo.mp4`](demo/Picture-Book-Writer-Demo.mp4)

## Use it in your web browser (no install)

Open **https://s-hilton.github.io/Children-s-book-processor/** in **Google Chrome** or **Microsoft Edge**.

- When you create a book, a save window opens. Choose your **Desktop** and click **Save**. After that, the book saves itself to that file as you type.
- To open a book, click it under **Your books**, or click **Open a book from another folder** and pick the `.pbook` file on your Desktop.
- The first time you open a book in a session, the browser asks for permission to edit the file. Choose **Allow** (or **Allow on every visit**).
- Optional: click the **Install** icon in the address bar to put the app on your Desktop like a normal program.
- Firefox and Safari can't save straight to the Desktop. In those browsers, books are kept inside the browser, and **Save** downloads a copy.
- The web version and the desktop app use the same `.pbook` files, so you can switch between them.

## Getting the desktop app

Go to this project's **Releases** page on GitHub and download the installer for your computer. Step-by-step instructions are on the download page (also in [`docs/RELEASE_NOTES.md`](docs/RELEASE_NOTES.md)).

- **Windows:** `Picture-Book-Writer-Setup-1.0.0.exe`. It installs and adds an icon to your Desktop.
- **Mac:** `Picture-Book-Writer-1.0.0-Mac.dmg`. Drag the app to Applications.

## What it does

| Feature | Why it helps |
|---|---|
| **Pages and spreads** | You write on two facing pages at a time, just like an open book. Standard sizes: 32 pages (the most common), 24, 40, or a 12-page board book. |
| **Book Map** | Thumbnails of every spread, so you can see the whole book at once and jump to any page. |
| **Picture ideas (art notes)** | A yellow note box on every page for describing the illustration. You don't need to be an illustrator. |
| **Add sketches or pictures** | Drop a sketch or a reference picture onto any page, or stretch one picture across both pages. |
| **Page types** | Mark pages as Title, Copyright, Dedication, Story, Picture only, or Extra info. |
| **Page-turn reminders** | A prompt at the end of each right-hand page, because a good page turn keeps kids eager to see what happens next. |
| **Story Check** | Live word count against a goal, reading level, read-aloud time, busy pages (over 60 words), long sentences, big words and words you repeat a lot. |
| **Rhyme finder** | An offline rhyming dictionary. Everyday words are shown in bold, and clicking a word adds it to your page. |
| **Beat counter** | Counts the syllables in each line and labels the rhyme pattern (A/B/…), so you can check rhyme and rhythm. |
| **Preview** | Flip through your book full-screen, like a reader would. |
| **Read Aloud** | The computer reads your story out loud, page by page. |
| **Make a PDF** | Choose **Manuscript** (the standard submission format for publishers and agents: double-spaced, with contact details, word count and page breaks) or **Book layout** (a printable mock-up of the book, called a "dummy"). |
| **Book Details** | Title, author, contact details, age group, a short pitch, characters, and notes. |
| **Saves by itself** | New books are saved on your **Desktop** and keep saving as you type. Older versions are backed up quietly too. |
| **Spell check** | Misspelled words are underlined. Right-click one to see suggestions. |
| **Help and guided tour** | A short tour the first time you use it, tooltips on every button, and a plain-English Help page. |

### Saving and opening books
- Books are saved as **`.pbook`** files on your **Desktop**, unless you choose another folder.
- To keep working on a book, open the app and click it in **Your books**. You can also double-click the `.pbook` file.
- If the app ever closes before a new book is saved, it offers to bring that book back the next time you open it.

## For developers

```bash
npm install
npm start               # run the app
npm run dist:win        # build a Windows installer (needs Windows, or Wine on Linux)
npm run dist:mac        # build a Mac .dmg (needs macOS)
npm run dist:linux      # build a Linux AppImage
```

Every push builds the Windows and Mac installers in GitHub Actions (`.github/workflows/build.yml`) and publishes them to a GitHub Release.

- `src/main.js`: the Electron main process. It handles windows, files, PDF export and menus.
- `src/preload.js`: a small, safe bridge between the app's pages and the file system.
- `src/renderer/`: the user interface, written in plain HTML, CSS and JavaScript with no framework.
- `src/renderer/words-data.js`: the rhyme and syllable dictionary. It's generated by `npm run build-words` from the CMU Pronouncing Dictionary and the SCOWL word lists.
- `demo/record-demo.js`: records the walkthrough video automatically.

Fonts (Nunito, Fredoka and Literata) are bundled under the SIL Open Font License.
